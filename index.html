BTD6 Mods on Linux – Installation Guide

This guide explains how to get mods working for Bloons TD 6 on Linux using MelonLoader + BTD Mod Helper (the standard approach in 2026). Most players run BTD6 via Steam Proton.

Last tested/updated: February 2026

Important: Using mods will flag your account. You will be unable to play ranked modes (Contested Territory, Ranked Boss Events, etc.) with modded saves. Use an alternate account for modding to avoid issues on your main profile.

Prerequisites

  • BTD6 installed via Steam (recommended for Proton) or Heroic Launcher (Epic version possible but more fiddly)
  • Proton Experimental or a recent GE-Proton version enabled for BTD6
  • .NET 6.0 runtime installed in your Wine/Proton prefix (usually required)
  • Basic terminal comfort (you'll run a few commands)

Step 1 – Install MelonLoader

  1. Follow the official MelonLoader Linux instructions.
  2. For Steam Proton users (most common):
    • Locate your BTD6 Proton prefix: ~/.steam/steam/steamapps/compatdata/960090/pfx/
    • Download the latest MelonLoader (alpha or stable — check which works with current BTD6)
    • Use the manual zip method or native Linux bootstrap if available
    • Extract/copy MelonLoader files directly into your BTD6 game folder (the one containing BloonsTD6.exe)
  3. Set up overrides (important for version.dll): 
    WINEPREFIX=~/.steam/steam/steamapps/compatdata/960090/pfx/ winecfg
    In the Libraries tab: add version → set to native, builtin (or builtin, native — test both if issues)
  4. Install .NET 6 if not already present: 
    WINEPREFIX=~/.steam/steam/steamapps/compatdata/960090/pfx/ winetricks dotnet6
    Or use protontricks 960090 dotnet6 if you have protontricks installed.

Step 2 – Install BTD Mod Helper

  1. Download the latest Btd6ModHelper.dll from: Direct link
  2. In your BTD6 game folder, create a Mods folder if it doesn't exist
  3. Place Btd6ModHelper.dll inside the Mods folder
Tip: The folder structure should look like:
BloonsTD6/
├─ BloonsTD6.exe
├─ version.dll (from MelonLoader)
├─ MelonLoader/
└─ Mods/
   └─ Btd6ModHelper.dll

Step 3 – Installing Mods

  1. Launch the game once with MelonLoader + Mod Helper installed → it should generate config files and show a mod menu
  2. Use the in-game Mod Browser (via Mod Helper) to download and enable mods directly — easiest method
  3. Alternatively, download .dll mods from GitHub and place them in the Mods folder
  4. Restart the game after adding mods

Troubleshooting

Game crashes / doesn't start

  • Make sure .NET 6 is installed in the prefix
  • Check version.dll override in winecfg
  • Try a different Proton version (GE-Proton often works better)
  • Delete MelonLoader folder and reinstall MelonLoader

No mod menu / Mod Helper not loading

  • Confirm Btd6ModHelper.dll is in Mods/ (not Plugins/ or root)
  • Check Latest.log in MelonLoader/Logs/ for errors

Black screen / infinite loading

  • Disable conflicting mods one by one
  • Verify game files in Steam
  • Try PROTON_LOG=1 %command% in launch options to generate logs

If you run into something not covered here, check the MelonLoader Discord, BTD6 modding communities on Reddit/Discord, or open an issue on your repo.
