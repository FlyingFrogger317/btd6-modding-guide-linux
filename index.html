BTD6 Mods on Linux – Installation Guide

This guide uses the automated MelonLoader Linux installer + BTD Mod Helper for modding Bloons TD 6 on Linux (via Steam Proton). Follow the exact order to avoid issues like the Mods folder being wiped.

Last tested/updated: February 2026

Important: Mods disable ranked play (Contested Territory, Ranked Boss Events, etc.) and can flag your account. Use a secondary/alt account for modded play.

Prerequisites

  • BTD6 installed via Steam with Proton (Epic untested)
  • Terminal access (for chmod)

Step 1 – Install MelonLoader

There is no need to install .NET6 manually, MelonLoader does that automatically.

  1. Visit the MelonLoader wiki: Automated Installation
  2. Download the **Linux version** of the installer.
  3. Make it executable: 
    chmod +x MelonLoader.Installer.Linux
    (Adjust filename if needed)
  4. Run it: 
    ./MelonLoader.Installer.Linux
  5. Select **Bloons TD 6** (it should auto-detect via Steam; if not, browse to ~/.steam/steam/steamapps/common/Bloons TD 6/).
  6. Choose the latest compatible version (stable or alpha/nightly — check BTD6 modding communities for current recommendation).
  7. Install. It copies files to your BTD6 folder (including version.dll and MelonLoader/ folder).

Step 2 – Set Steam Launch Options

  1. Right-click Bloons TD 6 in Steam → Properties → General → Launch Options
  2. Add exactly: 
    WINEDLLOVERRIDES="version=n,b" %command%

This allows MelonLoader to load.

Step 3 – Initialize MelonLoader

  1. Launch BTD6 through Steam.
  2. MelonLoader initializes on first run — the game loads (may take longer), then you can exit/close it normally (or it may close itself).
  3. This creates necessary folders like Mods/, Plugins/, and configs in your BTD6 game directory.
Critical: Do NOT create a Mods folder manually before this first launch. If you do, MelonLoader may wipe/delete/overwrite it during initialization, causing issues.

Step 4 – Install BTD Mod Helper (After First Launch)

  1. Now that the Mods folder exists (created by the first launch), download the latest Btd6ModHelper.dll: Direct download
  2. Go to your BTD6 game folder (e.g. ~/.steam/steam/steamapps/common/Bloons TD 6/).
  3. Place Btd6ModHelper.dll directly into the existing Mods folder.

Step 5 – Verification

  1. Launch BTD6 again through Steam.
  2. You should now see the Mod Helper UI/menu in-game (e.g., a mods button or overlay — usually in the main menu or bottom-right).

Step 6 – Adding More Mods

  1. Use the in-game Mod Browser (via BTD Mod Helper) to download/enable mods — easiest and safest.
  2. Or manually: Download .dll files and drop them into the Mods folder.
  3. Restart the game to load new mods.
